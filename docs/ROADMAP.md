# Agent Meeting Room Roadmap

This roadmap keeps the near-term product ideas in one place so improvements can be shipped day by day without turning the app into a loose pile of features.

## Next Product Ideas

- Repo / Project Context Import: load a local project folder so agents can review, plan, and debate with codebase context.
- Desktop App Polish: tray behavior, cleaner local launch flow, release packaging polish, and optional auto-start later.
- Meeting Packs: reusable room packs for startup founder meetings, code review, research debate, product planning, hiring panels, and script brainstorming.
- Export Center: Markdown, PDF, HTML report, JSON, and later DOCX exports from meetings and structured deliveries.
- Agent Personas Library: save, edit, and reuse personas such as Skeptical Reviewer, Product Manager, Security Engineer, Researcher, and Teacher.
- Meeting Memory Timeline: surface past decisions, open questions, repeated themes, and what changed since the last meeting.
- Structured Delivery Templates v2: PRDs, technical plans, bug reports, release checklists, investor-style summaries, and learning notes.
- Voice / Presentation Mode: present meeting summaries aloud and later produce slideshow-style summaries.
- Agent Debate Scorecards: compare options by risk, effort, confidence, user impact, and recommended next action.
- Portfolio Demo Mode: guided sample meeting that quickly shows visitors what the product can do.

## Current Focus

The current priority is making Agent Meeting Room useful against real user work:

1. Load local project context.
2. Let agents discuss that project with concise file previews.
3. Turn the discussion into implementation plans, PR descriptions, release notes, or review summaries.
