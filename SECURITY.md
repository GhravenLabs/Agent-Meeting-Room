# Security Policy

Agent Meeting Room is a public portfolio project for local and optional cloud
AI-agent meetings. Do not paste secrets, private client data, API keys, or
sensitive personal data into a public or shared instance.

## Reporting

Please report suspected security issues privately by email:

- rolly.calma.0217@gmail.com

Include the affected route or command, what you expected, what happened, and
reproduction steps if possible.

## Scope

In scope:

- Flask app code in this repository
- Local memory, transcript, and export behavior
- GitHub Actions workflows in this repository

Out of scope:

- Third-party model providers such as Anthropic or Ollama
- Browser extensions, proxies, or deployment platforms not controlled by this repo
- Denial-of-service testing or attempts to access private accounts

Please do not include API keys, private chats, or client data in reports.
